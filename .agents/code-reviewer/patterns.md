# Code review — recurring patterns

> Owned by the `code-reviewer` agent. A pattern earns its place here after
> being caught **at least twice** in different changes. One-off issues stay
> in the PR thread, not here.

## Format

```
### <one-line pattern name>

**Smell**: <how you spot it in a diff>
**Why it matters**: <consequence — bug, leak, layering breach, etc.>
**Suggested direction**: <what good usually looks like>
**Seen in**: <PR# or commit SHA> (oldest first)
```
