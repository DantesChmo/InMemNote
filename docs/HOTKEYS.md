# Хоткеи

## Где живут

| Файл                                                       | Назначение                                  |
|------------------------------------------------------------|---------------------------------------------|
| `config/hotkeys.json`                                      | дефолты, упаковываются с приложением        |
| `~/Library/Application Support/Inmemnote/hotkeys.json`     | переопределение пользователя (опционально)  |

Если пользовательский файл не валиден по схеме — мы логируем причину и
откатываемся на дефолты, чтобы приложение продолжало стартовать.

## Формат

Строка-акселератор в формате Electron. Документация:
<https://www.electronjs.org/docs/latest/api/accelerator>

Примеры:

| Команда      | Дефолт                          |
|--------------|---------------------------------|
| `openDraft`  | `CommandOrControl+Shift+Space`  |

## Как переопределить локально

1. Скопируйте `config/hotkeys.json` в `~/Library/Application Support/Inmemnote/hotkeys.json`.
2. Поменяйте значения. Например:

   ```json
   {
     "openDraft": "CommandOrControl+Option+N"
   }
   ```

3. Перезапустите приложение.

## Конфликты

macOS-сочетания вроде `CommandOrControl+Space` (Spotlight) уже заняты
системой. Electron вернёт `false` при попытке регистрации — мы это
логируем и оставляем хоткей незарегистрированным; UI сообщает пользователю.
